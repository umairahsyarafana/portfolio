Maybank Website — UX Improvement Concept

Role: UI/UX Designer Type: Personal / Concept Project Year: 2025

Overview

An independent redesign concept exploring usability improvements to a banking website's navigation, visual hierarchy, and mobile responsiveness, using the Maybank website as a case study.

Note: this is an independent student concept project for portfolio purposes, and is not affiliated with, endorsed by, or representative of Maybank.

The Problem

Banking websites often pack dense information and navigation into a small space, making it hard for users to quickly find the service they need. The goal was to identify and redesign the friction points in the existing experience.

Design Process

As the UI/UX Designer, I ran a heuristic evaluation of the existing website to identify usability issues, then redesigned the navigation and key pages with clearer visual hierarchy, finishing with hi-fi mockups in Figma.

Outcome

The redesign concept proposed a clearer information hierarchy and a more scannable layout, aimed at reducing the steps it takes users to find and use common banking services.
