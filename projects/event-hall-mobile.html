Event Hall Booking — Mobile App

Role: Mobile App Developer Type: Academic Project Year: 2025

Overview

Event Hall Booking is a mobile app that lets users browse, compare, and book event halls and venues for weddings, corporate events, and celebrations — all from their phone.

The Problem

Booking an event hall traditionally means calling around, visiting venues in person, and juggling phone-based availability checks — slow and error-prone, especially when comparing multiple venues at once.

My Role & Approach

As the Mobile App Developer, I designed and built the customer-facing app in Flutter, with Firebase handling real-time availability data and booking confirmations, and Figma used to plan the screens and user flow upfront.

Key Features

  • Browse and filter event halls by location, capacity, and price
  • Hall detail pages with photos, amenities, and reviews
  • Real-time availability calendar
  • In-app booking and reservation management
  • Push notifications for booking confirmations and reminders
